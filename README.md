# 🚀 Minimal Next.js Starter Template

A lightweight, streamlined Next.js template tailored for side projects and solo developers who want to skip unnecessary boilerplate and build quickly.

> Powered by **[Next-starter-skolaczk](https://github.com/skolaczk/next-starter)**

---

## ✨ Features & Advantages

* **No Overhead:** Removed heavy features rarely used in solo development (e.g., L10N / i18n).
* **Simplified Architecture:** Reduced code complexity to help you focus purely on core business logic.
* **Maximized Productivity:** Clean structure optimized for fast iteration and rapid prototyping.
* **Lean Tooling:** Stripped out bulky CI/testing setups like Husky and Playwright to keep things lightweight.

---

## 🎯 When to Use

* You want to build a simple MVP or lightweight project without being bogged down by complex templates.
* You need a fast-bootstrapping setup for personal, casual side projects.

## ⛔ When NOT to Use

* You are planning a large-scale enterprise application.
* You expect active multi-developer collaboration or open-source external contributions.

# 🚀 Next.js 개인 프로젝트 전용 템플릿

개인 프로젝트 및 1인 개발 시 불필요한 보일러플레이트를 줄이고 빠른 개발 속도를 확보하기 위해 최적화된 Next.js 템플릿입니다.

> **Powered By** [Next-starter-skolaczk](https://github.com/skolaczk/next-starter)

---

### 💡 이 템플릿의 장점
1. **오버헤드 절감:** L10N(다국어 지원) 등 소규모 개발에서 거의 쓰이지 않는 비대해진 기능 전면 제거
2. **코드 복잡성 해소:** 전반적인 기능을 간소화하여 소규모 환경에 불필요한 과도한 추상화 최소화
3. **생산성 증대:** 직관적이고 경량화된 구조 개선을 통해 개발 속도 극대화
4. **의존성 슬림화:** Husky, Playwright 등 1인 프로젝트에 과도한 테스트/포맷팅 자동화 도구를 제거하여 가볍게 유지

---

### 👍 이 템플릿을 추천하는 경우
* 간단한 기능을 구현하려는데, 기존 헤비한 템플릿들의 구조가 오히려 개발 속도를 저해할 때
* 빠른 프로토타이핑이나 개인 프로젝트용으로 자유롭게 막 다룰 템플릿이 필요할 때

### 👎 이 템플릿을 추천하지 않는 경우
* 대규모 엔터프라이즈급 프로젝트를 기획 중인 경우
* 외부 기여자들과의 협업 및 엄격한 코드 검증 파이프라인이 필요한 경우
